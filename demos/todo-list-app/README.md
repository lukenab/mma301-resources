# To-do List App

A simple React Native application to manage tasks, built with Expo and
React Navigation.

## Features

- Add, delete, and view task details.
- Tab Navigation for Tasks and Info.
- Stack Navigation for task details.
- Drawer Navigation for Home and Settings.

## Setup

1. Install Node.js, Expo CLI, and LDPlayer9.
2. Clone this repository.
3. Run `npm install` to install dependencies.
4. Start the app with `npx expo start`.
5. Open Expo Go on LDPlayer9 and scan the QR code.

## Technologies

- React Native
- Expo CLI
- React Navigation
- LDPlayer9

## Directory Structure

- `assets/`: Resources (images, fonts).
- `components/`: Reusable components.
- `screens/`: App screens.
- `navigation/`: Navigation setup.
